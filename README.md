🌟 Arivoli – Gamified STEM Learning Platform
📖 About the Project

Arivoli is an interactive and gamified STEM learning platform designed to make education more engaging and accessible for students. The application supports learning in English and Tamil and uses interactive games and activities to improve student engagement.

The platform focuses on creating a fun learning experience while also helping track and understand students' learning progress.

✨ Features
🎮 Interactive STEM learning games
🌐 Bilingual learning support – English & Tamil
📱 Offline-ready learning experience
📊 Student learning analytics
🧠 Engaging and interactive educational activities
🎯 Designed to make STEM learning more accessible and enjoyable
🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript
Languages: English, Tamil
Other: Offline-ready web application technologies
🎯 Objective

The main objective of Arivoli is to make STEM education more engaging and accessible by combining technology, gamification, and multilingual learning. The platform aims to support students by providing an interactive learning environment rather than relying only on traditional learning methods.
